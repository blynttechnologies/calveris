# Calveris Website Clone & 5 Strategic Redesign Concepts

A complete, componentized clone of [https://calveris.co.uk/](https://calveris.co.uk/) with **5 distinct redesign directions** built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**, accompanied by an **Executive PDF Presentation Book**.

---

## 🚀 Quick Start

```bash
# Start development server
npm run dev
```

1. Open [http://localhost:3000](http://localhost:3000) in your browser.
2. Click **"5 Redesigns (PDF)"** in the top navigation or use the floating **Redesign Studio** pill in the bottom-right corner.
3. Switch between any of the 5 designs with **1 click** to see the whole live website transform in real time!
4. Download the generated **PDF Design Book** directly from the page or open [Calveris-5-Redesign-Concepts.pdf](file:///d:/Project/dd/Calveris-5-Redesign-Concepts.pdf).
